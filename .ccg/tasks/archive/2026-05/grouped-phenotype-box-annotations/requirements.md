# Requirements

- With population data and multiple retained haplotypes, render a grouped boxplot by population with haplotypes as the grouped boxes.
- Add star-format statistical annotations inside the plot.
- For multiple haplotypes, annotate both within-population haplotype comparisons and between-population comparisons for each haplotype.
- If only one haplotype is retained, annotate only between-population comparisons.
- Keep computation in backend phenotype helpers and keep the plotting layer focused on rendering.
